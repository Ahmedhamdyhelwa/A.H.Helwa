1. نظرة عامة على النظام

ما هو A.H.Helwa ERP؟

هو نظام محاسبي ومخزون ومبيعات سحابي (SaaS) متعدد المستأجرين، يعني تقدر تستضيفه مرة واحدة وتأجّره لعدد لا نهائي من العملاء، كل عميل يفتح حسابه ويدير مشروعه بمعزل تام عن غيره.

🛒 المبيعات (نقطة البيع)

لإنشاء فاتورة:

  1. اضغط "فاتورة جديدة"
  2. ابحث عن المنتج بالاسم أو امسح الباركود
  3. اضغط على المنتج لإضافته للسلة
  4. عدّل الكمية، أضف خصم إذا أردت
  5. اختر العميل (أو اتركه عميل نقدي)
  6. أدخل المبلغ المدفوع
  7. اضغط "حفظ الفاتورة"
  8. اطبع الفاتورة بزر "طباعة"
تنبيه: عند حفظ الفاتورة، يتم تلقائياً:
  • خصم الكمية من المخزون
  • تسجيل الحركة في سجل المخزون
  • إضافة المبلغ غير المسدد لحساب العميل

🚚 المشتريات

مثل المبيعات تماماً ولكن للشراء من الموردين. عند حفظ فاتورة شراء:

4. كيفية تشغيله محلياً وعلى الإنترنت

الخيار 1: للتجربة فقط — GitHub Codespaces (مجاني)

كل ما تفعله: تذهب للمستودع → Code → Codespaces → Create. يعمل في المتصفح بدون أي تثبيت. مجاني 60 ساعة شهرياً.

عيب: الـ Codespace يتوقف تلقائياً بعد ساعات من عدم الاستخدام، والبيانات تختفي عند حذفه. مناسب للتجربة فقط، ليس للاستخدام الحقيقي.

الخيار 2: للاستخدام الحقيقي — النشر على الإنترنت دائم (مجاني للبداية)

الأدوات المطلوبة (كلها مجانية):

الخدمةالوظيفةالمجاني فيها
Vercelيستضيف الموقع نفسه100 جيجا/شهر حركة، يكفي لـ آلاف الزيارات
Neonقاعدة بيانات PostgreSQL سحابية500 ميجا، يكفي لـ 50-100 عميل
GitHubتخزين الكودمجاني للمستودعات الخاصة
Cloudflareدومين وحماية (اختياري)الدومين 10-15 دولار/سنة

خطوات النشر:

  1. أنشئ قاعدة بيانات على Neon:
    • سجّل دخول على neon.tech
    • أنشئ Project جديد
    • انسخ "Connection String"
  2. انشر على Vercel:
    • سجّل دخول على vercel.com بحساب GitHub
    • Add New → Project → اختر مستودع A.H.Helwa
    • غيّر الـ Branch لـ claude/upbeat-rubin-QdQ8Y
    • أضف Environment Variables:
      • DATABASE_URL = الذي نسخته من Neon
      • JWT_SECRET = نص عشوائي طويل (30 حرف)
    • اضغط Deploy
  3. ربط دومين خاص (اختياري):
    • اشتر دومين من Namecheap أو GoDaddy (مثلاً helwa-erp.com)
    • في Vercel: Settings → Domains → أضف الدومين واتبع التعليمات

5. تحويله إلى منتج SaaS (اشتراك شهري)

ما الذي ينقص النظام لتحويله إلى منتج كامل؟

المرحلة الأولى — إضافات أساسية (الأولوية الأولى)

  1. بوابة دفع: Paymob / Fawry / Stripe لاستلام الاشتراكات الشهرية
  2. صفحة تسعير وخطط: مجاني / أساسي / احترافي / المؤسسات
  3. قيود التشغيل:
    • الخطة المجانية: 100 فاتورة / شهر
    • الأساسي: 1,000 فاتورة
    • الاحترافي: غير محدود
  4. صفحة هبوط Landing Page: تشرح المنتج وتجمع العملاء المحتملين
  5. إعدادات الفاتورة: لوجو، معلومات الضريبة، شكل الطباعة
  6. نسخ احتياطية تلقائية: يومية على S3 أو Backblaze
  7. دعم فني: WhatsApp business + شات داخل النظام

المرحلة الثانية — تمييز عن المنافسين

  1. تطبيق موبايل (iOS + Android) باستخدام React Native
  2. تكامل واتساب لإرسال الفواتير تلقائياً
  3. طباعة على أجهزة فواتير حرارية (POS Printers)
  4. قارئ باركود متكامل
  5. ذكاء اصطناعي للتنبؤ بالمبيعات والمخزون
  6. تكامل مع منصات الـ E-commerce (Shopify، Salla، Zid)
  7. للمطاعم: شاشة المطبخ، طلبات الديليفري
  8. API مفتوحة للتكامل مع أنظمة أخرى

7. استراتيجيات البيع والتسويق

أولاً: حدد عميلك المثالي

لا تستهدف الجميع في البداية. اختر نشاط واحد وتخصّص فيه أولاً (مثلاً: الصيدليات الصغيرة في مدينتك).

قنوات التسويق (مرتّبة بالأولوية)

1. التسويق المباشر (الأقوى للبداية)

  • زِر 10 محلات يومياً وقدّم النظام شخصياً
  • اعرض شاشة الموبايل/التابلت أمامه وأظهر سرعة الفاتورة
  • اعرض شهر مجاني بدون أي التزام
  • استهدف الأنشطة التي تستخدم دفاتر ورقية حالياً (أسهل تحويل)

2. مجموعات فيسبوك المتخصصة

  • انضم لمجموعات "أصحاب الصيدليات" و"تجار سوبر ماركت"
  • قدّم محتوى مفيد (مش بيع مباشر)
  • اعرض حالات نجاح: "كيف وفّر محل X مبلغ Y بسبب اكتشاف نقص في المخزون"

3. إعلانات فيسبوك وإنستجرام

  • ميزانية بداية: 50 ج.م/يوم
  • استهدف: أصحاب أعمال + اهتمامات (محاسبة، إدارة محلات)
  • المحتوى: فيديو 30 ثانية يُظهر شاشة البيع وسرعة العمل

4. شراكات مع موزّعين

  • اتفق مع موزّعي أجهزة الكاشير على بيع نظامك مع كل جهاز
  • اعطهم عمولة 20-30% لمدة سنة

5. اليوتيوب والتيك توك

  • فيديوهات "ازاي تدير محلك" — مش بيع مباشر
  • قصص نجاح عملاء حقيقيين
  • مقارنات بين الطرق التقليدية والنظام

6. SEO ومحرّكات البحث

  • اكتب مقالات بكلمات مفتاحية مثل: "برنامج محاسبة صيدليات"، "نظام كاشير سوبر ماركت"
  • استخدم Google Ads بميزانية صغيرة في البداية

سكربت بيع لـ Cold Call

أنت: صباح الخير أستاذ [اسم]، أنا [اسمك] من شركة [اسمك]. وقتك معايا دقيقة؟

أنت: بشوف إن حضرتك بتدير محل [نوع نشاط]. لو أقدر أوفّرلك نظام يحسب ليك الأرباح والخسائر تلقائياً ويعرّفك المنتجات اللي خلصت من المخزن قبل ما العميل يطلبها، هل ده يهمّك؟

8. كيفية تطويره بنفسك وأنت لست مبرمج

الخيار الأكثر واقعية: استخدم الذكاء الاصطناعي

الأدوات المطلوبة:

  • GitHub Copilot ($10/شهر): مساعد كتابة كود داخل المحرر
  • Cursor IDE (مجاني للبداية): محرر كود بذكاء اصطناعي مدمج
  • Claude / ChatGPT Plus ($20/شهر): لاستشارات وحل المشاكل

طريقة العمل خطوة بخطوة:

  1. افتح المشروع في Codespace
  2. افتح ChatGPT أو Claude
  3. اكتب الميزة الجديدة المطلوبة بالعربي مثلاً:
    "أريد إضافة صفحة لإدارة الطاولات في المطعم، كل طاولة لها رقم وحالة (متاحة/مشغولة) وعدد الكراسي."
  4. اطلب من الـ AI: "اكتب لي الكود وأخبرني أي ملفات أضيفها وأين"
  5. انسخ الكود في الملفات المطلوبة
  6. اختبر، إذا ظهر خطأ ارجع للـ AI وأخبره بالخطأ
  7. كرّر حتى تعمل

  • سياسة الخصوصية وشروط الاستخدام: ضروري قانوناً مع SaaS
  • حقوق ملكية فكرية: سجّل الاسم التجاري والشعار

مخاطر تقنية يجب التحوّط ضدها

  • فقدان البيانات: نسخ احتياطية يومية تلقائية على مكان منفصل
  • الاختراق الأمني: SSL + كلمات مرور قوية + 2FA للملاك
  • توقف الخدمة: اختر مقدّمي خدمة موثوقين + Status Page
  • فقدان مفتاح JWT_SECRET: احفظه في 3 أماكن منفصلة

مخاطر تجارية

  • الاعتماد على عميل واحد كبير: لا تتجاوز 20% من إيرادك من عميل واحد
  • المنافسة: هناك أنظمة موجودة (Foodics، Daftra)، تميّز بالسعر + الدعم
  • التغيرات القانونية: تابع تحديثات مصلحة الضرائب باستمرار

  • اشترِ دومين بشكل احترافي (helwa-erp.com مثلاً)

12. أسئلة شائعة

س1: هل أحتاج خبرة في البرمجة لأشغّل المشروع؟

ج: لا، استخدم GitHub Codespaces للتجربة، ثم Vercel + Neon للنشر — كل خطوة بالضغط على أزرار، بدون كتابة كود.

س2: كم تكلفة الاستضافة الشهرية؟

ج: للبداية حتى 100 عميل: 0-20 دولار/شهر. بعد ذلك ترتفع تدريجياً مع نمو عملاءك (وإيراداتك تنمو أسرع منها).

س3: ماذا لو فقد عميل بياناته؟

ج: Neon يحفظ نسخ احتياطية تلقائية. تأكد من إعداد Point-in-Time Recovery. أضف أيضاً نسخة احتياطية يومية على S3.

س4: كيف أحوّل من Codespace إلى نشر دائم؟

ج: Codespace للتجربة فقط. للنشر الحقيقي اتبع الخطوات في الفصل 4 (Vercel + Neon).

س5: هل أحتاج رخصة لاستخدام كود مفتوح المصدر؟

ج: الكود الذي تم إنشاؤه ملكك بالكامل. المكتبات المستخدمة كلها بترخيص MIT (مجاني للاستخدام التجاري). لا توجد قيود.

س6: كيف أتأكد إن العميل لا يرى بيانات عميل آخر؟

ج: النظام مبني على Multi-tenant architecture — كل سجل في كل جدول يحمل tenantId ويتم التحقق منه في كل عملية. عميلك لا يرى إلا بياناته.

س7: كم وقت أحتاج لإطلاق المنتج تجارياً؟

ج: 30-60 يوم بحد أقصى. أهم خطوات: النشر، بوابة الدفع، Landing Page، ثم البيع.

س8: ماذا لو كنت لا أعرف الإنجليزية؟

ج: النظام كله بالعربي. الاستضافة (Vercel/Neon) لها واجهات بسيطة. أي مشكلة استخدم Google Translate أو ChatGPT للترجمة.

س9: هل يمكن تشغيله بدون إنترنت؟

ج: حالياً لا، لكن يمكن تطوير وضع Offline-first في المرحلة الثانية — يعمل بدون نت ويزامن البيانات عند العودة.

س10: كيف أتعامل مع عميل لا يدفع؟

ج: أضف وضع "تجميد الحساب" — العميل يرى رسالة "يرجى تجديد الاشتراك" ولا يستطيع إصدار فواتير جديدة لكن بياناته القديمة تبقى محفوظة.
